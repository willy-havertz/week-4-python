# File Read & Write Challenge

This project demonstrates how to build a Python program that reads from a file, applies a modification, and writes the modified content to a new file. It also includes robust error handling to manage cases where the file doesn't exist or cannot be read.

## Features

- **File Reading:** Reads the contents of a file specified by the user.
- **Content Modification:** Transforms the file content (e.g., converts text to uppercase). This part can be easily customized to apply other modifications.
- **File Writing:** Writes the modified content to a new file specified by the user.
- **Error Handling:** Handles common errors such as missing files, permission issues, and unexpected exceptions.
